# GBS المنتصر — سهم الوجهة 🧭

أداة الموقع الجغرافي مستخرجة من تطبيق «منتصر النور» لتعمل **تطبيقًا مستقلًا**:
سهم أصفر يدلّك على أي وجهة مع المسافة، دقة عالية (فلتر كالمان + متوسط مرجّح + Vincenty على WGS84)،
بوصلة بتعويض الميل، حفظ موقف السيارة والأماكن، وإدارة كاملة للأذونات.
**الـ GPS والسهم يعملان بدون إنترنت**، والإنترنت مطلوب فقط للبحث عن مكان بالاسم.

## هيكل المستودع

```
www/                    ← التطبيق نفسه (هذا كل ما يُنشر)
  index.html            الإطار: الشريط العلوي، النوافذ، الإشعارات
  js/shim.js            بديل لما كانت الأداة تأخذه من التطبيق الأم (الإعدادات، toast، التأكيد، FUN)
  js/geo.js             طبقة الموقع GEO — منسوخة كما هي من الملف الأصلي
  js/gps-tool.js        أداة GPS — منسوخة كما هي (حُذف فقط كود تثبيتها في «مركز الأدوات»)
  js/app.js             التشغيل + دليل الاستخدام + النسخ الاحتياطي + زر التثبيت
  css/luxe.css          طبقة التصميم الفاخرة (شكل فقط)
  js/luxe.js            تحسينات العرض: حركة سلسة للمؤشر، أرقام الدرجات، اختصار الملاحظات
  js/store.js           تخزين الرحلات على الهاتف (IndexedDB) مع بديل localStorage
  js/trips.js           تسجيل الرحلات، الاستئناف، السجل، GPX، العودة إلى نقطة الانطلاق، خدمة الخلفية في أندرويد
  js/map.js             خريطة بلاطات دون اتصال (Canvas) مع حفظ البلاطات المعروضة
  js/ext.js             مؤشر الثقة، مسار الحركة مقابل اتجاه الهاتف، حالة البوصلة، الشمال الحقيقي، وضع الصحراء
  manifest.webmanifest  ملف تطبيق الويب (PWA)
  sw.js                 عامل الخدمة للعمل بدون إنترنت
  icons/                الأيقونات
assets/                 أيقونات المصدر لتطبيق أندرويد
capacitor.config.json   إعداد Capacitor (معرّف التطبيق: com.almuntasir.gbs)
scripts/patch-android.js يضيف أذونات الموقع إلى AndroidManifest
.github/workflows/      بناء APK ونشر تطبيق الويب تلقائيًا
```

## الطريقة 1: تثبيته تطبيق ويب (الأسهل، بدون أي برامج)

1. ارفع المستودع إلى GitHub (الفرع `main`).
2. من **Settings ← Pages** اختر **Source: GitHub Actions**.
3. بعد دقيقة يُنشر على `https://<اسمك>.github.io/<المستودع>/`.
4. افتح الرابط في **Chrome على الهاتف** ← القائمة ⋮ ← **تثبيت التطبيق** (أو زر 📲 في أعلى التطبيق).

يظهر على الشاشة الرئيسية بأيقونته، يفتح بملء الشاشة، ويعمل بدون إنترنت بعد أول فتح.
> يلزم اتصال HTTPS حتى يعمل الموقع، وهذا متوفّر تلقائيًا في GitHub Pages.

## الطريقة 2: ملف APK لأندرويد (تطبيق أصلي عبر Capacitor)

### تلقائيًا عبر GitHub (بدون Android Studio)
1. ارفع المستودع إلى GitHub. سيعمل workflow **«بناء APK لأندرويد»** عند كل دفع إلى `main`.
2. افتح تبويب **Actions** ← آخر تشغيل ← في الأسفل **Artifacts** ← نزّل `GBS-Almuntasir-apk`.
3. فكّ الضغط وانقل `GBS-Almuntasir.apk` إلى الهاتف وثبّته (اسمح بـ «التثبيت من مصادر غير معروفة»).

لإصدار رسمي في صفحة Releases:
```bash
git tag v1.0.0 && git push origin v1.0.0
```

### محليًا على جهازك
يتطلب Node.js 18+ و JDK 17 و Android SDK (أو Android Studio).
```bash
npm install
npm run android:add      # ينشئ مجلد android ويضيف أذونات الموقع
npm run android:icons    # اختياري: يولّد أيقونات أندرويد من مجلد assets
npm run sync
npm run apk              # الناتج: android/app/build/outputs/apk/debug/app-debug.apk
# أو افتحه في Android Studio:  npx cap open android
```

داخل تطبيق أندرويد تستخدم الأداة تلقائيًا:
- `@capacitor/geolocation` — إذن الموقع الدقيق/التقريبي من النظام
- `capacitor-native-settings` — زر يفتح إعدادات الموقع أو التطبيق مباشرة عند الرفض
- `@capacitor/share` — مشاركة موقعك

## التجربة محليًا في المتصفح
```bash
npm run serve        # ثم افتح http://localhost:8080
```
(المتصفح يسمح بالموقع على `localhost` دون HTTPS.)

## الخريطة دون اتصال
- كل منطقة تتصفّحها وأنت متصل تُحفظ على الهاتف وتظهر لاحقًا دون إنترنت. تصفّح مسار رحلتك قبل السفر على مستويات التكبير التي تحتاجها.
- سياسة OpenStreetMap و OpenTopoMap تمنع التنزيل الجماعي المسبق، لذلك زر «تنزيل المنطقة» يعمل فقط مع «مصدر مخصّص» تملك حق استخدامه دون اتصال.
- بيانات الطرق في مناطق واسعة من السودان والصحراء ناقصة. الخط المتقطع على الخريطة اتجاه مباشر وليس طريقًا.

## البيانات
تُحفظ الوجهات في ذاكرة التطبيق (localStorage). من زر 💾 يمكنك **تصدير** نسخة احتياطية JSON و**استيرادها**.
يقبل الاستيراد أيضًا ملف نسخة احتياطية من التطبيق الأصلي إذا كان يحتوي `settings.gpsNav`.
